        Add items

        Set the release date and shop once, then add every comic from that same order before submitting - one shipment, one form. The order number and shipping cost are both optional, but adding them lets that shop's shipping figure be exact rather than an estimate. Submitting keeps the shop, date, tracking number, and paid status set for next time - handy when one delivery covers several separate orders (a Whatnot bundle, say), since only the order number and the item itself need changing between them.

        Paste order text

        Paste a Forbidden Planet order-history page and every detail - shop, order number, release date, paid status - comes in automatically. Anything else falls back to a generic reader that only picks up a name, a price, and a nearby date where one's genuinely present; it never guesses a price or invents a name.

          General preferences

          Sync

          Optional - connects this app straight to your own self-hosted Ka-Ching! server so both stay in step. Leave blank to keep using this app fully standalone, same as always.

          Only needed if syncing seems stuck, or some items never seem to update - makes the next sync re-check everything instead of just what's changed recently.

          Data

          CSV is a plain spreadsheet of everything tracked, for opening elsewhere - not something this app can read back in. The JSON backup is the reverse: made for restoring back into this app, not for opening in a spreadsheet.

          Danger zone

          Deletes every tracked item on this device. There's no undo for this.

          About

          Ka-Ching! answers exactly two questions - what's due this week and what it'll cost, and what this month (and next) is forecast to come to. Nothing more: no collection cataloguing, no accounts, no cloud.
